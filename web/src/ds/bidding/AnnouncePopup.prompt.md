Popup auto-disparaissante posée sur le tapis : preneur, atout, contrat, contre. Présentation pure — ne touche jamais au moteur.

```jsx
<AnnouncePopup taker="Iznogoud" team="b" atout="hearts" contract={110} kind="contre" />
```

Disparaît seule via `anim-announce`. Pour ré-afficher, remonte le composant (clé sur l'id d'annonce).
