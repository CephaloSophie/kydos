Badge d'annonce : passe, contrat chiffré + couleur, contré, surcontré. Coloré par équipe sur un contrat ; contre/surcontre gardent leur teinte d'alerte.

```jsx
<BidBadge kind="pass" />
<BidBadge kind="bid" value={110} suit="hearts" team="a" animate />
<BidBadge kind="contre" />
<BidBadge kind="surcontre" size="lg" />
```
