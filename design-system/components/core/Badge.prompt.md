Pastille de statut compacte. Sert aux états de table (live, privée), de robot (actif), de tournoi (à venir).

```jsx
<Badge tone="spark" dot>En direct</Badge>
<Badge tone="success">Contrat réussi</Badge>
<Badge tone="warning" solid>3 places</Badge>
```

Tonalités : `neutral | accent | success | warning | error | info | spark`. `solid` pour fond plein, `dot` pour le point de statut.
