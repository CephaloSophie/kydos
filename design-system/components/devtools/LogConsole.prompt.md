Console devtools de l'entraînement. Niveaux error→trace, filtres masquables (toggles d'en-tête), repliable, auto-scroll en bas.

```jsx
<LogConsole defaultHidden={['trace']} entries={[
  {ts:'12:04:01', level:'info', msg:'pli 3 → Sud (R♥)'},
  {ts:'12:04:01', level:'debug', msg:'eval main Ouest = 0.62'},
  {ts:'12:04:02', level:'error', msg:'contrat non rempli (−160)'},
]} />
```
